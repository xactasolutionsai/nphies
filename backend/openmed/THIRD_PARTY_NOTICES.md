# Third-party components

This adapter uses OpenMed 2.3.0 by the OpenMed contributors, distributed under Apache-2.0:
https://github.com/maziyarpanahi/openmed/tree/v2.3.0
https://github.com/maziyarpanahi/openmed/blob/v2.3.0/LICENSE

Model identifiers, immutable revisions, and declared licenses are recorded in `models.json`.
The download script retains the original model cards (README.md). Dependencies remain in the
isolated Python environment with their own distribution metadata and licenses. No upstream
application source or logo was copied into this adapter. Review the corresponding licenses
when redistributing an environment or model artifacts.
