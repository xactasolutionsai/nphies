## حدود التفعيل

لم يقدم المستخدم ملف إعدادات ربط المنشأة بنفيس، ولا يمكن استخراج كل هذه الإعدادات من نسخة قاعدة البيانات. بقي الاستطلاع المجدول معطلاً، ولم يُسمح بالاتصال التجريبي غير المشفر ولم تُرسل معاملات حية. يجب ضبط إعدادات المنشأة الصحيحة في `/etc/nafes/app.env` قبل اختبار الربط الحي. لم يُغيّر كود ربط نفيس.

OpenMed يعمل على الخادم نفسه باستخدام نموذجين محليين إنجليزيين، واتصال مستقل محدود الصلاحيات إلى القاعدة المستوردة. خدمات Ollama القديمة ليست مثبتة على هذا الخادم؛ هذا لا يمنع عمل OpenMed أو إدارة السجلات، لكنه يعني أن مزايا الذكاء القديمة التي تعتمد Ollama تحتاج إعداداً منفصلاً.

## التشغيل والاسترجاع

```bash
sudo systemctl status nafes nginx postgresql
sudo systemctl restart nafes
sudo systemctl list-timers nafes-cert-renew.timer
sudo journalctl -u nafes --since '10 minutes ago'
```

لا تنشر سجل الخدمة علناً؛ قد تحتوي رسائل التطبيق القديمة على معلومات حساسة عند حدوث أخطاء.

المحفوظات على الخادم:

- `/var/lib/nafes-import/final_DB.rar`: الأرشيف الأصلي.
- `/var/lib/nafes-import/final_DB`: ملف PostgreSQL المستخرج.
- `/var/backups/nafes/before-user-import.dump`: القاعدة الأولية قبل طلب الاستيراد.
- `/var/backups/nafes/imported-and-configured.dump`: نسخة القاعدة بعد الاستيراد والتهيئة.
- `/var/backups/nafes/import-verification.json`: نتيجة مقارنة أعداد السجلات.
- `/etc/nafes/before-import.env`: الإعدادات السابقة للاتصال بقاعدة التثبيت الأولية.

للاسترجاع، استعد النسخة المطلوبة إلى قاعدة منفصلة أولاً، وافحصها ثم غيّر اتصال التطبيق أثناء إيقاف الخدمة. لا تُشغّل أدوات التثبيت الفارغ على القاعدة المستوردة. ملفات `deploy/` توثق إجراءات هذا النشر؛ بعضها أحادي الاستخدام ويحتاج مراجعة قبل تكراره.
